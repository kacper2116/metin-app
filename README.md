## About app
This app simulates the item upgrade system from Metin2.
You can spawn classic items from Metin2 golden era (2007-2010) and try to upgrade them just like in the original game.

## Install locally
```bash
git clone https://github.com/kacper2116/metin-app
git cd metin-app
git install
npm run dev
```
